# 坦克大战 Tank Battle

经典 Battle City（坦克大战）风格的 HTML5 网页游戏，纯 Canvas + 原生 JavaScript 实现，**零依赖、零构建**，双击 `index.html` 即可游玩。

## 🎮 在线试玩

GitHub Pages：<https://Mzhenchen.github.io/tank-battle/>

## ✨ 游戏特性

- 3 张手工设计关卡，砖墙可被逐块（按象限）轰开
- 4 种敌方坦克：普通 / 快速 / 炮弹 / 装甲（4 血）
- 敌方 AI：追踪玩家与基地、随机变向、墙边自动转向
- 道具系统：★ 升级火力、⛨ 无敌护盾、♥ 额外生命
- 坦克星级系统：提升弹速 → 双发 → 炮弹可击穿钢墙
- 树林藏身、水域挡路、基地（鹰）保卫玩法
- WebAudio 合成音效（射击 / 爆炸 / 拾取 / 过关）
- 爆炸粒子特效、出生保护罩、奖励敌人

## 🕹️ 操作方式

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动坦克 |
| `空格` / `J` | 射击 |
| `回车` | 开始游戏 / 下一关 |
| `P` | 暂停 / 继续 |
| `M` | 静音开关 |

## 🏆 得分规则

| 敌方坦克 | 分数 |
| --- | --- |
| 普通 | 100 |
| 快速 | 200 |
| 炮弹 | 300 |
| 装甲 | 400 |
| 奖励车（白色闪烁） | 500 + 掉落道具 |
| 过关奖励 | 300 |

## 🚀 本地运行

无需安装任何东西，直接用浏览器打开 `index.html` 即可。
也可以起一个本地服务器（可选）：

```bash
npx serve .
# 或
python -m http.server 8000
```

## 📝 自定义关卡

关卡是 `game.js` 中 `LEVELS` 数组里的字符串地图：

- `.` 空地　`#` 砖墙　`@` 钢墙　`~` 水域　`T` 树林　`B` 基地
- 每张地图 **26 列 × 19 行**，照着现有格式加新数组即可
